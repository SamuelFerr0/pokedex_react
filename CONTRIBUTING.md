# 🤝 Guia de Contribuição

1. Faça um **fork** do repositório e crie uma branch: `git checkout -b feat/minha-melhoria`.
2. Instale as dependências (`npm install`) e rode `npm run dev`.
3. Antes de abrir o PR, execute `npm run lint` e `npm run build`.
4. Use mensagens de commit claras (ex.: `feat: adiciona comparação de Pokémon`).
5. Abra um **Pull Request** descrevendo o que mudou e por quê.

Ideias de melhoria: comparação de dois Pokémon, paginação, testes com Vitest, deploy na Vercel.
